# ProposalKit for Claude

Write client proposals, quotes and statements of work with Claude, then turn
them into documents your client can open. ProposalKit lays the proposal out
with a cover, scope, a pricing table and terms, brands it from your website,
and publishes it to a live link that emails you the first time your client
opens it. You can also export a PDF.

## What's inside

- **ProposalKit connector** (`https://api.proposalkit.io/mcp`): the tools
  Claude uses to create, edit, brand, publish and export proposals.
- **client-proposal skill**: tells Claude when a request is a client proposal,
  quote or statement of work, and how to build it in ProposalKit. It leaves
  grant, research, academic and internal team proposals alone.

## Using it

Ask for a proposal in your own words, for example: "Write a proposal for my
client for a brand identity project, $3,800, three-week turnaround." Claude
offers to build it in ProposalKit, writes each section into a live preview,
and hands you a link or a PDF when it's done.

Drafting needs no account. Publishing a live link asks you to sign in to a
free ProposalKit account, and the draft moves into it.

## Privacy

ProposalKit receives only the requests Claude makes to its tools, never the
rest of your conversation. See [proposalkit.io/privacy](https://proposalkit.io/privacy).
